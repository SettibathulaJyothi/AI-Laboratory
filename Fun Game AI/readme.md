# Computer Vision Learning Lab

An interactive web application that helps students explore how computers see, process, and understand images.

## ✨ Features

- 🖼️ Explore images using real-life sample images and image uploads.
- 🎨 Understand RGB and grayscale images.
- 🔍 Explore pixels and pixel values.
- 📊 Visualize image histograms and pixel matrices.
- 🧠 Learn basic computer vision concepts through interactive activities.
- 🎮 Practice image processing with hands-on experiments.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Canvas API

## 🚀 How to Use

1. Open the application.
2. Select a sample image or upload your own image.
3. Explore image colors, pixels, and processing results.
4. Interact with the available tools to understand computer vision.

## 🎯 Learning Objectives

- Understand how computers represent images.
- Explore RGB color channels and grayscale conversion.
- Learn how pixel values affect images.
- Visualize image data through histograms and pixel matrices.
- Develop practical knowledge of computer vision.

## 👩‍🎓 Target Audience

Students, beginners, and anyone interested in learning computer vision through interactive experiments.
