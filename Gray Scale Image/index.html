QUESTION 1 OF 6

What does a grayscale value of 0 represent?

Remember: A grayscale pixel stores one brightness value. An RGB pixel stores three channel values: Red, Green and Blue. In an 8-bit channel, each value ranges from 0 to 255.

Grayscale formula: Gray = 0.299R + 0.587G + 0.114B
