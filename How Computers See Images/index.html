5. What Is the Computer Actually Reading?🤔

🔲 Pixels

An image is made of tiny picture elements called pixels. Each pixel stores colour information.

🔢 Values: 0–255

Zero means no intensity in a channel. 255 means maximum intensity.

🌈 RGB Together

The red, green and blue values combine to represent each pixel's colour.

Examples: RGB (255, 0, 0) is red. RGB (0, 255, 0) is green. RGB (0, 0, 255) is blue. RGB (255, 255, 255) is white. RGB (0, 0, 0) is black.

These grayscale channel views show the intensity of each colour channel, not three separate photographs.
