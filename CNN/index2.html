Welcome, AI Explorer! 👋

A CNN is a neural network designed to recognize patterns in images. It can learn edges, textures, shapes, and eventually objects.

🔍 1. Convolution

A small filter, called a kernel, slides across an image and calculates how strongly local pixels match its values.

⚡ 2. ReLU

ReLU replaces negative values with zero and leaves positive values unchanged.

🧊 3. Pooling

Pooling summarizes small regions of a feature map, often reducing its width and height.

🎯 4. Classification

A trained CNN can use learned features to estimate which classes are present in an image.

📷 Why does a CNN need layers?

Input image→ Convolution→ ReLU→ Pooling→ Classification

Think of a CNN as a detective: it notices small clues, combines useful clues, and finally makes a prediction. Real CNN architectures may repeat these operations several times.

The rule

ReLU(x) = max(0, x)

If x is positive, the output is x.

If x is negative, the output is zero.

If x is zero, the output is zero.

🎯 What is the fully connected layer?

A classifier uses learned features to calculate class scores. A softmax layer may convert these scores into probabilities. Predictions are not guaranteed to be correct.

Learned features→ Class scores→ Predicted class

Real CNNs can use fully connected layers, global average pooling, or other classification heads.
