Welcome, AI Explorer! 👋

A CNN is a neural network designed to recognize patterns in images. It can learn edges, textures, shapes, and eventually objects.

🔍 1. Convolution

A small filter, called a kernel, slides across an image and calculates how strongly local pixels match its values.

⚡ 2. ReLU

Rectified Linear Unit replaces negative values with zero and leaves positive values unchanged.

🧊 3. Pooling

Pooling summarizes small regions of a feature map, often reducing its width and height.

🎯 4. Classification

A trained CNN can use learned features to estimate which classes are present in an image.

📷 Why does a CNN need layers?

Input image→ Convolution→ ReLU→ Pooling→ Classification

Think of it as a detective: first it notices small clues, then combines useful clues, and finally makes a prediction. Real CNN architectures may repeat convolution, activation, and pooling several times.

The rule

ReLU(x) = max(0, x)

If x is positive, the output is x.

If x is negative, the output is zero.

If x is zero, the output is zero.

🎯 What is the fully connected layer?

A typical classifier takes learned features, converts them into a suitable representation, and computes class scores. A softmax layer may convert scores into probabilities. These are not guaranteed to be correct.

Learned features→Class scores→Predicted class

The real architecture can vary: some CNNs use global average pooling, fully connected layers, or other classification heads.
